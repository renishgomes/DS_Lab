# Lab 2 – Data Wrangling and Transformation

## Objective
Perform data wrangling and transformation on real-world datasets using Python and Pandas — handling missing values, removing duplicates, correcting data types, filtering data, scaling/normalizing features, detecting and treating outliers, encoding categorical variables, and producing model-ready datasets.

## Part 1 — Tutorial: Student Placement Dataset (`data.csv`)
1. Import libraries (`pandas`, `numpy`, `matplotlib`, `scikit-learn`, `scipy`).
2. Load the dataset and explore its structure (`head`, `shape`, `dtypes`, `describe`, `info`, duplicate check).
3. Handle missing values:
   - Drop rows with a missing `salary` (target) value.
   - Impute `hsc_p`, `degree_p`, `etest_p` with their column mean.
4. Feature scaling: `StandardScaler` and `MinMaxScaler` on the numerical columns.
5. Split into `X` (features) / `Y` (`salary`) and save `Pre.csv`.
6. Outlier detection with boxplots and the Z-score method (`|Z| > 3`).
7. Outlier treatment via capping and flooring (5th/95th percentile).
8. Encode categorical variables (`gender`, `hsc_s`, `degree_t`, `specialisation`) using `LabelEncoder` and One-Hot Encoding.
9. Final validation (missing values, dtypes, shape) and save `Final.csv`.

## Part 2 — Exercise: Automobile Dataset (`Automobile.csv`)
A fully solved, 19-task exercise covering:
- Loading & exploring the dataset (shape, dtypes, descriptive stats, numeric vs categorical columns).
- Missing-value detection/imputation (mean for numeric, mode for categorical).
- Duplicate detection & removal.
- Cleaning the `horsepower` column (`?` → `NaN` → numeric → imputed).
- Transforming `origin` into readable labels, creating `weight_kg`, `mpg_category`, `vehicle_age`.
- Renaming columns (`mpg`→`miles_per_gallon`, `horsepower`→`hp`, `weight`→`weight_lbs`, `model_year`→`year`).
- Filtering vehicles by `mpg`, `hp`, `cylinders`, `year`, and `origin`.
- Label Encoding and One-Hot Encoding of `origin`, with a written comparison of the two approaches.
- Outlier detection via Z-scores across all numeric features.
- Standardization (`StandardScaler`) and Normalization (`MinMaxScaler`) with a written comparison of when to use each.
- Building `X`/`Y`, saving `automobile_X_Y.csv`, and saving the final `automobile_preprocessed.csv`.

## How to Run
1. Clone this repository.
2. Install the dependencies:
   ```bash
   pip install pandas numpy matplotlib scikit-learn scipy jupyter
   ```
3. Launch Jupyter and run all cells:
   ```bash
   jupyter notebook Ex2.ipynb
   ```
   The notebook runs top-to-bottom with no manual intervention and will regenerate `Pre.csv`, `Final.csv`, `automobile_X_Y.csv`, and `automobile_preprocessed.csv`.
